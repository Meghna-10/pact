How it works

One question, answered with evidence: does this billing still match what the customer agreed to?

1Capture the agreement

Upload or paste the terms. The text is fingerprinted with SHA-256 so the record can't quietly change.

2Confirm the terms

Price, interval, trial and fees are extracted with the sentence each came from. The customer corrects and confirms.

3Read PayPal

TermsTrace reads the plan and subscription from the PayPal sandbox, or receives a verified webhook.

4Compare and keep evidence

Plain code compares each field: Match, Mismatch, Needs review or Not enough evidence. Every step is logged.

No hidden AI decision

Extraction can be wrong, so it never counts as consent. The comparison itself is deterministic code.

Every source labelled

Live sandbox data, test fixtures and manual demo data are badged differently on every screen.

Records, not actions

TermsTrace never charges, cancels, refunds or disputes. It shows what changed and what to review.
